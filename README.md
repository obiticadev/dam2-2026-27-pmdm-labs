# Laboratorios de PMDM 2026-27

Ejercicios de clase y practicas pequenas de desarrollo movil y multimedia.

## Estructura

- `tareas/`: proyectos Android pequenos organizados por unidad.
- `practicas/`: entregas evaluables que no necesiten repositorio propio.

Se conservan Gradle, el wrapper y los recursos de cada aplicacion. Las aplicaciones
destacadas o de varias semanas tendran repositorio propio.
