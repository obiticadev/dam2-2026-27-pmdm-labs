# Laboratorios de PMDM 2026-27

Ejercicios de clase y prácticas pequeñas de desarrollo móvil y multimedia.

## Estructura

- `tareas/`: proyectos Android pequeños organizados por unidad.
- `practicas/`: entregas evaluables que no necesiten repositorio propio.

Se conservan Gradle, el wrapper y los recursos de cada aplicación. Las aplicaciones
destacadas o de varias semanas tendrán repositorio propio.
